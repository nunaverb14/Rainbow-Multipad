# Installation
I used the KMK Firmware Repository for programming the board the code hasn't been tested yet **this is just a demo**. It also uses the default code in the repo with only edit to the pin numbers.
https://github.com/KMKfw/kmk_firmware

## Downloads
To program the board you will need the latest version of Circuit Python for the Waveshare ESP32-S3 Zero and the KMK firmware.  

- https://circuitpython.org/board/waveshare_esp32_s3_zero/
- https://github.com/KMKfw/kmk_firmware/archive/refs/heads/main.zip
